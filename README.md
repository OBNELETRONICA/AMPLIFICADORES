# Sistema para Circuitos de Amplificadores
---------------------------------------------
Coletânea de circuitos encontrados, fazer testes
de bancada, comprovar o funcionamento, atualizar
os circuitos para garantir seu pleno e satisfatório
funcionamento. Elaborar as PCB, fazer a montagem
do protótipo.
---------------------------------------------- 
## usando modelos encontrados na NET
- Atualizando os circuitos e elaborando a PCB
	- Amplificador 100W com 2N3055
	- Amplificador 100W com MOS-FET
	- Amplificador 100W com Transistores NPN/PNP
	- Amplificador 100W fonte simétrica e 2x 2SC5200
---------------------------------------------
